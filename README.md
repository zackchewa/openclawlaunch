# OpenClaw Launch

Managed hosting for open-source AI agents. Pick OpenClaw, Hermes Agent or a coding harness, click deploy, and it is live in about 30 seconds.

## What it is

Self-hosting an agent means a VPS or a spare Mac, Docker, ports and firewall rules, config files, TLS certificates and health checks, usually 2 to 6 hours before the first message. OpenClaw Launch does all of that for you. Each agent gets its own sandboxed cloud machine, and you manage it from the browser.

## Pick a runtime

| Runtime | What it is | Talks to you on |
|---|---|---|
| [OpenClaw](https://github.com/openclaw/openclaw) | The original open-source agent framework (MIT) and the largest community. The safe default. | Telegram, Discord, WhatsApp, WeChat, Feishu, Web UI |
| [Hermes Agent](https://github.com/NousResearch/hermes-agent) | By Nous Research, built around memory that lasts across sessions. | The same, plus Slack |
| Coding harness | Not a chat bot: a cloud dev box with Claude Code, Codex, OpenCode and pi installed, driven from a browser terminal. Code and logins survive a reset. | Browser terminal |

Same plans and same infrastructure for all three. You choose at deploy time.

## What your agent can do

- A real computer, not just a chat window: full terminal with root inside its own container, a file manager, and a live browser you can watch and take over for a login or a 2FA tap.
- Connect apps without writing code: Gmail, GitHub, Google Drive and Calendar, Slack, Notion and 1,000+ more integrations, plus a catalog of Chinese apps at [/zh/china-apps](https://openclawlaunch.com/zh/china-apps).
- Thousands of community skills, and open-source tools you can install with a click (n8n, Ollama, ComfyUI, Crawl4AI, SearXNG and more).
- Host websites with automatic HTTPS, run scheduled jobs and daily reports, browse and fill forms, generate images and video.
- Bot teams: give each bot one job and they hand work to each other, in the dashboard or in a Telegram group.

## Models

GPT, Claude, Gemini, Grok, DeepSeek, Kimi, GLM, MiniMax, Qwen and more, switchable at any time without redeploying. Three ways to pay for them:

- Included AI credits on every paid plan, plus free models.
- Bring your own key: OpenAI, Anthropic, Google, OpenRouter or any OpenAI-compatible endpoint.
- Use an existing ChatGPT subscription instead of per-token API billing.

The current list and per-token prices are on [openclawlaunch.com/models](https://openclawlaunch.com/models).

## Quick start

1. Go to [openclawlaunch.com](https://openclawlaunch.com).

3. Click Deploy. Your agent is live in about 30 seconds.
