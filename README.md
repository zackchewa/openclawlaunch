## What is OpenClaw Launch?

OpenClaw Launch is a managed hosting platform for
[OpenClaw](https://github.com/nicepkg/openclaw) — the open-source AI agent framework
with 15,000+ GitHub stars.

Instead of spending 2-6 hours on Docker setup, server configuration, and networking,
OpenClaw Launch lets you:

- **Configure** your AI agent visually — no config files, no terminal
- **Deploy** with one click in under 30 seconds
- **Connect** via Telegram, Discord, or the built-in Web UI

## Features

- Managed OpenClaw hosting with automatic updates
- Telegram & Discord bot hosting
- Browser-based Web UI
- Visual configurator — zero code required
- 8 AI models: GPT-5.2, Claude Opus 4.6, Gemini 3 Pro, DeepSeek, and more
- 5,700+ community skills on ClawHub
- Real-time logs & monitoring
- Auto SSL / HTTPS
- Encrypted configs (AES-256-GCM)

## Pricing

- **Lite** — $3/mo (first month), then $6/mo. 1 vCPU, 2 GB RAM, 10 GB storage.
- **Pro** — $20/mo. 2 vCPU, 4 GB RAM, 40 GB storage, up to 3 instances.

No markup on AI API usage. Pay provider rates directly.
